# 02 案例库 —— 说明与现状

对应需求：相似案例检索（FAISS Top-5，阈值 0.75，见技术方案 §3.3.5）；目标规模 **≥500 条** 结构化诈骗案例。

## ⚠️ 本类别是最大的空缺项

**公开渠道没有现成的"结构化中文反诈案例库"数据集**（含标题/正文/诈骗类型/防范建议的 ≥500 条语料）。需要人工整理，预计 1–2 周。

## 可用的替代/补充数据

### ChiFraud（已部分落地，本目录 `ChiFraud/`）

- 来源：https://github.com/xuemingxxx/ChiFraud （论文：ChiFraud，中文欺诈文本检测数据集）
- 规模：59,106 条欺诈文本 + 352,328 条正常文本，11 个细分类别（见 `class.txt`）
- 协议：**CC BY-NC 4.0，仅限学术研究，禁止商用**（毕设可用）
- 已存放：`class.txt`（标签表）、`metadata.json`（数据集元信息，含 sha256 校验值）
- 未存放：`ChiFraud_train.csv`（47MB）、`ChiFraud_t2022.csv`、`ChiFraud_t2023.csv` —— 运行 `datasets/download_datasets.py` 自动拉取
- 用途定位：它**不能直接当案例库**（只有 label + text，无标题/建议/来源），但可：
  1. 作为相似检索的**向量语料底库**，验证 E3（相似度层对新型变体的召回提升）；
  2. 按 11 类标签筛选后，人工改写少量为结构化案例，加速案例库建设。

### 人工采集来源（清单中已标注）

| 来源 | 说明 |

## 表结构对齐

采集模板 `案例采集模板.csv` 的列与 fraud_case 表一一对应：

`(case_id, fraud_type, title, content, advice, source_url, status)`

- `fraud_type` 建议枚举：刷单返利 / 虚假投资理财 / 冒充客服 / 冒充公检法 / 贷款代办信用卡 / 冒充熟人 / 中奖诈骗 / 机票退改签 / 钓鱼链接 / 其他（与技术方案 fraud_type 枚举保持一致）
- `status`：`draft`（草稿）/ `reviewed`（已校对）/ `published`（入库），配合规则"样本先冻结再回放"
