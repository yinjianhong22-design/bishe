## 一键补齐大数据集

本目录下执行（纯标准库，无需装依赖；已存在的文件自动跳过）：

```
python download_datasets.py
```

自动下载：FBS_SMS 全部 13 类（含最相关的银行钓鱼类 FR_Phishing_Bank，296KB）、
SpamMessage 带/不带标签短信（58MB/14MB）、ChiFraud 三个 CSV（共约 97MB）、
OpenPhish 最新 feed、URLHaus 在线恶意 URL、Tranco Top-1M 域名白名单（自动解压）。

## 注意事项

- FBS_SMS 文本为**分词后 + 匿名化**格式（字间有空格，号码/卡号/链接替换为 `CELLPHONE/BANK/URL` 等占位符），详见 `01_诈骗短信/FBS_SMS/README.md`；
- `FR_Phishing_Other_dedup.txt` 是去重版（源文件 95% 为同一条重复短信），完整版由脚本拉取；
- 本目录所有电话号种子均为**合成测试数据**，非真实号码。
