# 05 攻防测试样本 —— 说明与构建方案

对应需求：M6 攻防测试平台；E4（红蓝对抗：攻击前检出率 ≥90%，字符级变体 ASR ≤30%，语义级 ≤50%）、
E5（注入防御：防御开启后 ASR ≤5% 且相对下降 ≥50%）。

## ✅ 本类别不需要外部数据集

攻防样本是**程序生成**的（技术方案 M6.1/M6.2），外部只起"种子"作用：

```
原始样本（来自 01_诈骗短信/FBS_SMS 或 02_案例库）
   │
   ├── 变体生成 mutator.py ──┬─ 字符级：谐音字表替换 / 拆字 / emoji 随机插入（纯程序，确定性）
   │                        ├─ 语义级：改写 / 方言化（调 LLM）
   │                        └─ 拼接级：按句拆分模拟多轮
   │
   └── 注入样本 injector.py ── 注入模板库 × 样本拼接（模板见 injection_templates.json）
```

## 本目录已存放

- `injection_templates.json` —— 提示词注入模板种子库（5 类 20 条，对应 §3.6.2 注入模板库），
  `injector.py` 直接加载后与原样本拼接生成注入样本，每条需标注 `injection_type`。

## 构建要点（对齐技术方案）

1. **可追溯**：每个变体/注入样本记录 `origin_sample_id`（§3.6.1）；
2. **先冻结再回放**：样本版本冻结后才能在 replay.py 中回放，保证 ASR 可复算（§3.6.3）；
3. **配对评估**：原始集与变体集各跑一遍批量核验，对比检出率得 ASR（§3.6.3）；
4. **字符级种子表**：谐音字表（如 微→薇/威、钱→浅/前）、拆字表（信→亻言）、
   emoji 集——可在开发时内置到 `mutator.py` 配置，无需外部数据；
5. **注入防御对照**：同一注入集在防御开/关下各跑一次（§3.6.6 三层防护：输入隔离/输出校验/最小权限），输出 ASR 对比。

## 建议规模

| 样本组 | 建议数量 | 来源 |
|---|---|---|
| 原始攻击基样本 | 100–200 条 | FBS_SMS 的 FR_* 类别 + 案例库新型话术 |
| 字符级变体 | 每基样本 × 3–5 | mutator.py 生成 |
| 语义级变体 | 每基样本 × 2–3 | LLM 改写 |
| 注入样本 | 每注入模板 × 若干基样本 | injector.py 生成 |
